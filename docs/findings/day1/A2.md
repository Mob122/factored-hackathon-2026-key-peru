# A2 - Disputed charges closed as a valid charge

Generated by `ml/analysis/day1/A2_dispute_outcomes.py` on 2026-09-28 over `ml/data/02_intermediate/complaints.parquet` (67,095 complaints). Groups come from A1: **core** = Transactions / Cargo no reconocido (13,580), **extended** = Fees / Cobro indebido (13,553, sensitivity only), **rest** = Technical, Branch, Service (39,962). 'Decided' means status Resolved, Closed or Rejected.

## Hypothesis

Some unrecognized-charge complaints are closed as a valid charge, visible in the `resolution` text and in `compensation_granted`. If not, Track A can only rest on industry evidence.

## Verdict: **not testable with this dataset**

- **No outcome field.** `resolution` is one of 5 generic sentences shared by every category (text vs category p = 0.98). No text says the charge was valid (0 of 3,456 decided core disputes) and none says fraud (0).
- **The text contradicts the money.** 'Se otorgó compensación' rows are paid about as often as the rest (text vs compensation p = 0.78), so the text is not the decision.
- **Best proxy.** Reading 'explanation, no adjustment' as 'charge upheld' gives 20.28% of core disputes with a text, and 12.88% [11.80, 14.03] of decided core disputes when also requiring no compensation (16.49% [15.29, 17.77] adding Rejected). This is a template frequency (1 in 5), not evidence.
- **Everything looks like the rest.** Status (p = 0.19), compensation (p = 0.15) and resolution_days match Technical, Branch and Service.
- **Consequence (from 'Si falla'):** the 'closed as valid charge' thesis can only be supported by industry evidence, not by this dataset.
