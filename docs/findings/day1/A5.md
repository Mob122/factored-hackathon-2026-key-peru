# A5 - fraud_score leakage into is_fraud

Generated by `ml/analysis/day1/A5_fraud_score_leakage.py` on 2026-09-28 over `ml/data/02_intermediate/transactions.parquet` (4,425,008 transactions, 2023-06-17 to 2026-06-18). Temporal holdout = last 6 months (`transaction_date >= 2025-12-18`). ROC AUC and PR AUC (average precision) use fraud_score alone, on rows where it is non-null; CIs are a 1000-draw stratified bootstrap. Rates carry Wilson 95% CIs.

## Hypothesis

`fraud_score` does not leak `is_fraud`, so it can serve as a baseline. Flags set in advance: AUC > 0.95 -> likely leakage; AUC within 0.05 of 0.5 -> noise. Separately, if `is_fraud` tracks `transaction_status` (Declined / Reversed) the label is post-outcome.

## Verdict: **refuted: fraud_score leaks is_fraud by construction**

- **Prevalence.** is_fraud = 0.098% [0.095, 0.100] overall; drifting slightly down by year (p = 0.021), 0.100% [0.096, 0.103] before the holdout vs 0.087% [0.081, 0.094] in it (p = 0.0017). Tiny in absolute terms; the holdout's random PR AUC is lower to match.
- **AUC.** fraud_score alone: ROC AUC 0.8469, PR AUC 0.6946 (random 0.0010); holdout 0.8505 / 0.7153. Neither pre-set flag fires (not > 0.95, not ~ 0.5).
- **But the score is sampled from the label.** Non-fraud scores stop at 30; fraud scores are uniform on [0, 100]. 69.28% of frauds sit above 30 with 100% precision, the rest are pure noise. That is leakage, just partial, which is why AUC lands at ~0.85 instead of > 0.95.
- **No post-outcome leakage.** is_fraud is independent of transaction_status (p = 0.57; Declined/Reversed RR 0.97 [0.85, 1.10]) and response_code (p = 0.22). amount_usd and hour are noise too.
- **Consequence (from 'Si falla'):** exclude fraud_score as a baseline and as a feature. Any fraud model reporting AUC ~ 0.85 is reading back the generator. Without fraud_score, is_fraud has no learnable signal in the transaction columns checked, so a fraud-detection storyline is not supported by this dataset.

The rule `fraud_score > 30` on the holdout: precision 100.00% (369 TP, 0 FP), recall 71.37%. The score needs no fitting, so the holdout only checks that the relation is stable over time; it is.

The flag misses the pattern because the leakage is partial: the score reveals the label outright for ~70% of frauds and carries no information for the rest. No real risk score has zero false positives across 3,536,426 legitimate transactions above a single cut-off.
